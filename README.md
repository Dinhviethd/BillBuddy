# BillBuddy

**BillBuddy** is a smart personal finance and expense management application designed to help users track their spending, manage budgets, and gain better control over their financial health.

---

## Key Features

Based on the core functionalities, BillBuddy provides a comprehensive suite of tools for financial management:

### Account & Security
* **Authentication:** Secure user Registration and Login system.
* **Password Management:** Integrated "Forgot Password" and "Change Password" functionalities.
* **Profile Management:** Easily update and manage personal information.

### Expense Tracking
* **CRUD Operations:** Quickly Add, Edit, or Delete daily expenses.
* **Search Functionality:** Easily look up specific past transactions.
* **Smart Receipt Scanning:** Automatically calculate expense amounts by scanning invoices/receipts, saving time on manual entry.

### Statistics & Insights
* **Time-based Reports:** View detailed statistics and reports filtered by specific periods (Daily, Weekly, Monthly).
* **Budget Management:** Set and adjust your total manageable budget.
* **Overspending Alerts:** Receive push notifications immediately if your spending exceeds the predefined limit.

## Tech Stack

* **Language:** Kotlin
* **UI Framework:** Jetpack Compose
* **Build System:** Gradle with Kotlin DSL
* **Backend & Services:** Firebase (Authentication, Firestore, Cloud Storage)
